# نور AI — وجه ذكاء اصطناعي كيهضر معاك

ملي كتدخل للموقع كيبان ليك وجه ذكاء اصطناعي متحرك (العينين كيتبعو الماوس، كيرمش، والفم كيتحرك ملي كيهضر) وكيسلم عليك بالصوت. تقدر تهضر معاه بالكتابة ولا بالميكرو.

## المميزات
- وجه SVG متحرك: رمش، عينين كيتبعو الماوس/الصبع، فم كيتحرك مع الكلام، حواجب وتعابير (كيفكر / كيسمع / كيهضر).
- الصوت: كيقرا الأجوبة بصوت (Web Speech API).
- الميكرو: كيسمع ليك وكيحول الكلام لنص (أحسن فـ Chrome / Edge).
- 3 لغات: الدارجة/العربية، الفرنسية، الإنجليزية.
- كيخدم مع Claude باش يجاوب بذكاء حقيقي، وإلا ما كانش السيرفر كيخدم بردود بسيطة offline.

## التشغيل

```bash
cd ai-chat
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # المفتاح ديالك من console.anthropic.com
npm start
```

من بعد حل: http://localhost:3000

- `PORT` باش تبدل البورت (الافتراضي 3000).
- `CLAUDE_MODEL` باش تبدل الموديل (الافتراضي `claude-opus-5`).

> المفتاح كيبقى فالسيرفر وما كيوصلش للمتصفح.

## بلا سيرفر
تقدر تحل `public/index.html` مباشرة ولا تحطو فـ GitHub Pages — الوجه والصوت كيخدمو، ولكن الأجوبة غادي تكون بسيطة (offline).
